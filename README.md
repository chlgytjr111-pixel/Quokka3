# EZMaker 초음파 센서와 주사기 실험

EZMaker 보드가 USB 시리얼로 보내는 초음파 거리 또는 주사기 공기압 값을 브라우저에서 직접 확인하고 CSV로 저장하는 정적 웹앱입니다.

## 배포 주소

- 서비스: https://ezmaker-ultrasonic-sensor.vercel.app
- GitHub: https://github.com/chlgytjr111-pixel/Quokka3

## 제공 기능

- 초음파 거리(cm) 실시간 표시, 그래프, 표, CSV 저장
- 공기압(atm) 실시간 표시와 보일 법칙 `P₀V₀ = PV` 기반 주사기 부피 계산
- 초음파/공기압 센서별 수신 모드 분리
- 센서 없이 거리와 압력 화면을 시험하는 데모 슬라이더
- EZ·ON 블록코딩 화면 바로가기
- 장치 분리 감지, 원시 Serial 로그, 반응형 화면

## 사용 조건

- HTTPS로 열린 배포 주소
- 최신 데스크톱 Chrome 또는 Edge (Windows, macOS, ChromeOS)
- 운영체제에서 시리얼 포트로 인식되는 EZMaker 보드
- 선택한 센서 값을 시리얼로 계속 출력하도록 업로드된 보드 펌웨어

Safari, Firefox, 일반 모바일 브라우저에서는 Web Serial이 지원되지 않습니다. Android에서는 제조사 전용 앱이 필요할 수 있습니다.

## 연결 방법

1. **블록코딩하러 가기** 또는 EZ·ON/Arduino 환경에서 사용할 센서 코드를 보드에 업로드합니다.
2. EZ·ON, Arduino Serial Monitor 등 COM 포트를 쓰는 다른 프로그램을 닫습니다.
3. 보드를 USB로 연결하고 배포 주소를 데스크톱 Chrome/Edge에서 직접 엽니다.
4. 보드 코드와 같은 센서 탭(초음파 또는 주사기·공기압)을 선택합니다.
5. **장치 연결**을 누르고 EZMaker 포트를 선택합니다.
6. **초음파 기록 시작** 또는 **공기압 기록 시작**을 누릅니다.
7. 기록을 마친 뒤 **CSV 저장**을 누릅니다.

장치 연결 직후부터 원시 Serial 로그는 계속 읽고, **기록 시작/중지** 버튼은 현재 탭 값을 화면·표·CSV 데이터로 해석하고 기록할지를 제어합니다. 기록 시작 시 선택된 센서가 고정됩니다. 기록 도중 다른 탭으로 이동하면 같은 숫자 스트림이 다른 물리량으로 해석되지 않도록 자동으로 기록을 중지합니다.

## 현재 통신 규칙

첨부된 원본 HTML의 설정에 따라 다음 프로토콜을 사용합니다.

- `115200 baud`, 8 data bits, no parity, 1 stop bit, no flow control
- ASCII/UTF-8 텍스트
- 줄바꿈(`CR`, `LF`, `CRLF`)으로 구분된 프레임
- 한 줄의 첫 번째 숫자를 선택된 센서 값으로 사용
- 초음파 탭: 숫자를 거리 `cm`로 해석
- 공기압 탭: 보드에서 이미 변환한 압력 `atm`으로 해석
- 보드가 별도 요청 명령 없이 값을 계속 송신

예를 들어 `Distance: 34.7 cm`는 초음파 탭에서 `34.7 cm`, `Pressure: 1.025 atm`은 공기압 탭에서 `1.025 atm`으로 읽습니다.

연결은 되지만 값이 나타나지 않으면 다음을 확인하세요.

- 보드에 현재 탭과 같은 센서 스케치가 업로드되어 있는지
- 실제 baud rate가 115200인지
- 출력값이 줄바꿈이 포함된 텍스트인지
- 공기압 스케치가 analog raw가 아니라 atm 값을 출력하는지
- 페이지 아래 원시 Serial 로그에 어떤 값이 들어오는지

실제 장치의 원시 로그 5~10줄과 펌웨어의 `Serial.begin(...)`, `Serial.print(...)` 부분을 확인하면 프로토콜을 정확히 맞출 수 있습니다.

## 주사기 부피 계산

공기압 탭은 온도 변화가 작다고 가정하고 보일 법칙을 사용합니다.

```text
P₀V₀ = PV
V = V₀ × P₀ / P
```

기준 부피 `V₀`를 입력한 뒤 센서에서 정상 압력값을 받은 상태에서 **현재 압력을 기준압력으로 설정**을 누르면 `P₀`가 갱신됩니다. 데모 슬라이더 값은 기준압력으로 사용할 수 없습니다. `P₀` 또는 `V₀`가 바뀌면 이미 기록된 부피도 같은 기준으로 다시 계산됩니다. 이 계산은 교육용 시각화이며 정밀 계측 보정을 대신하지 않습니다.

## Vercel 구성

별도 빌드 과정이 없는 정적 프로젝트입니다.

- Framework Preset: `Other`
- Build Command: 없음
- Output Directory: `.`
- GitHub `main` 푸시 시 Vercel 프로덕션 자동 배포

## 파일 구성

- `index.html`: 두 실험 화면과 접근성 구조
- `styles.css`: 반응형 대시보드 스타일
- `app.js`: Web Serial 연결, 센서별 파싱, 기록, 차트, CSV 저장
- `vercel.json`: 정적 배포와 보안 헤더

## 보안과 개인정보

- 시리얼 데이터는 브라우저 메모리에서만 처리됩니다.
- 외부 분석 도구, 광고 스크립트, 원격 라이브러리를 사용하지 않습니다.
- Content Security Policy와 `serial=(self)` 권한 정책을 적용합니다.
- CSV 원시 문자열은 스프레드시트 수식 주입을 방지하도록 처리합니다.
