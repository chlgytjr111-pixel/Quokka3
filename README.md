# 이지메이커 초음파 센서 대시보드

이지메이커 보드가 USB 시리얼로 보내는 초음파 거리 값을 전용 데이터 분석 사이트 없이 브라우저에서 직접 확인하고 CSV로 저장하는 정적 웹앱입니다.

## 사용 조건

- HTTPS로 열린 배포 주소
- 최신 데스크톱 Chrome 또는 Edge (Windows, macOS, ChromeOS)
- 운영체제에서 시리얼 포트로 인식되는 이지메이커 보드
- 초음파 값을 시리얼로 계속 출력하도록 업로드된 보드 펌웨어

Safari, Firefox, 일반 모바일 브라우저에서는 Web Serial이 지원되지 않습니다. Android에서는 제조사 전용 앱이 필요할 수 있습니다.

## 연결 방법

1. 이지메이커 전용 사이트, Arduino Serial Monitor 등 COM 포트를 쓰는 다른 프로그램을 닫습니다.
2. 보드를 USB로 연결합니다. 드라이버가 필요한 보드라면 먼저 드라이버를 설치합니다.
3. 배포 주소를 데스크톱 Chrome/Edge에서 직접 엽니다. iframe이나 앱 내부 미리보기는 사용하지 않습니다.
4. **장치 연결**을 누르고 이지메이커 포트를 선택합니다.
5. 실시간 값이 보이면 **기록 시작**을 누릅니다.
6. 기록을 마친 뒤 **CSV 저장**을 누릅니다.

브라우저가 장치 선택과 연결 권한을 직접 관리하며, 센서 데이터는 서버로 전송되지 않습니다.

## 현재 통신 규칙

이 페이지는 첨부된 원본 HTML의 설정을 따라 다음 프로토콜을 가정합니다.

- `115200 baud`, 브라우저 기본 시리얼 설정(8 data bits, no parity, 1 stop bit)
- ASCII/UTF-8 텍스트
- 줄바꿈(`CR`, `LF`, `CRLF`)으로 구분된 프레임
- 한 줄에서 선택한 순번의 숫자를 거리(cm)로 사용
- 보드가 별도 요청 명령 없이 값을 계속 송신

예를 들어 `Distance: 34.7 cm`를 보내면 기본 설정에서 `34.7`을 읽습니다. 값의 단위나 형식이 다르면 페이지 아래 **원시 데이터 / 파서 설정**에서 숫자 순번, 배율, 보정값을 변경합니다.

연결은 되지만 값이 나타나지 않으면 다음을 확인하세요.

- 보드에 초음파 측정값을 출력하는 스케치가 먼저 업로드되어 있는지
- 실제 baud rate가 115200인지
- 데이터가 줄바꿈이 포함된 텍스트인지
- 원시 수신 로그에 어떤 값이 들어오는지

실제 장치의 원시 로그 5~10줄과 펌웨어의 `Serial.begin(...)`, `Serial.print(...)` 부분을 확인하면 프로토콜을 정확히 맞출 수 있습니다.

## 로컬 실행과 Vercel

별도 빌드 과정이 없는 정적 프로젝트입니다. Vercel 설정은 다음과 같습니다.

- Framework Preset: `Other`
- Build Command: 없음
- Output Directory: `.`

Web Serial은 보안 컨텍스트에서만 동작하므로 실사용 테스트는 고정된 Vercel 프로덕션 HTTPS 주소에서 진행하는 것이 좋습니다.

## 파일 구성

- `index.html`: 화면 구조와 접근성 정보
- `styles.css`: 반응형 대시보드 스타일
- `app.js`: Web Serial 연결, 파싱, 기록, 그래프, CSV 저장
- `vercel.json`: 정적 배포 보안 헤더

## 보안과 개인정보

- 시리얼 데이터는 브라우저 메모리에서만 처리됩니다.
- 외부 분석 도구, 광고 스크립트, 원격 라이브러리를 사용하지 않습니다.
- 엄격한 Content Security Policy와 `serial=(self)` 권한 정책을 적용합니다.
- CSV로 내려받은 원시 문자열은 스프레드시트 수식 주입을 방지하도록 처리합니다.
